# Контракт операции: голос за рифф

Лабораторная работа № 3. Операция реализована: страница голосования вызывает её через `castVote`, тот же запрос может отправить любой HTTP-клиент с сессией участника.

## 1. Операция

| | |
| --- | --- |
| Вызов | `POST /api/v1/rounds/{round_id}/votes` |
| Назначение | Сохранить один голос участника за чужой рифф текущего раунда |
| Сценарий | [US-8](01-requirements.md#us-8--голосование-без-подписей-авторов-fr-8) |
| Требование | [FR-8](01-requirements.md#2-требования) |
| Объявление | [`cast_vote`](../backend/src/app/api/v1/rounds.py) |
| Проверка правил | [`VoteService.cast`](../backend/src/app/services/vote.py) |
| Тело запроса и ответа | [`VoteIn`](../backend/src/app/schemas/round.py), [`VoteOut`](../backend/src/app/schemas/round.py) |

Базовый адрес локального API — `http://localhost:8000`. Ниже пути даны от `/api/v1`.

Голос — выбор одного чужого риффа. Свой рифф для участия не нужен. Имена авторов до `voting_ends_at` в ответах раунда не появляются. Повторный голос этим контрактом не описывается: у него другой ответ.

## 2. Кто вызывает и как

Вызывающая сторона — участник раунда, гость или владелец аккаунта. Игровые права у них одинаковые. Хост голосует тем же запросом.

Сессия — HttpOnly-кука `riff_session`, её выдаёт `POST /api/v1/session/guest` или вход в аккаунт. В JSON токена нет, JavaScript куку не читает. Срок куки — 7 суток. Запрос без неё не доходит до операции голосования.

Каждый изменяющий запрос, включая этот, требует заголовок `X-CSRF-Protection: 1`. Если клиент присылает `Origin`, значение должно быть `http://localhost:3000`, `http://127.0.0.1:3000` или собственным адресом API. Запрос без `Origin` проверку происхождения проходит. Тело — JSON, `Content-Type: application/json`.

Идентификатор чужого риффа берётся из `GET /api/v1/rounds/{round_id}` на стадии `voting`: у чужой работы `is_own` равен `false`, `author_id` и `author_nickname` равны `null`.

## 3. Условия вызова

Операция сохраняет голос, только если одновременно верно всё ниже.

1. Кука `riff_session` принадлежит действующей сессии.
2. Игрок состоит в комнате этого раунда.
3. Серверное время попадает в полуинтервал от `composing_ends_at` включительно до `voting_ends_at` не включая конец. Это пять минут после сочинения.
4. `riff_id` указывает на рифф этого раунда, и его автор — не вызывающий.
5. У вызывающего в этом раунде ещё нет голоса.

Проверка идёт в этом порядке. Голос за себя распознаётся только после пунктов 1–3. На стадии сочинения или результатов тот же `riff_id` даёт другой отказ и до сравнения автора не доходит.

## 4. Вход

| Место | Имя | Тип | Обязательность | Допустимые значения |
| --- | --- | --- | --- | --- |
| Путь | `round_id` | UUID | да | Идентификатор раунда, в котором вызывающий состоит |
| Заголовок | `Cookie` | строка | да | `riff_session=<значение из Set-Cookie>` |
| Заголовок | `X-CSRF-Protection` | строка | да | Ровно `1` |
| Заголовок | `Origin` | строка | нет | Если передан — один из разрешённых адресов из раздела 2 |
| Тело | `riff_id` | UUID | да | Рифф этого раунда; для успеха — чужой |

Других полей тело не требует.

## 5. Успешный результат

Код **201**. Тело — объект с тем же `riff_id`, который был передан. Голос записан. Идентификатор голоса и автор риффа в этот ответ не входят.

```json
{"riff_id": "11111111-1111-4111-8111-111111111111"}
```

Повторное чтение раунда тем же участником показывает `your_vote_riff_id` равным этому UUID и увеличивает `votes_count` на единицу. Пока не наступил `voting_ends_at`, авторы и число голосов у отдельных риффов остаются скрытыми, даже если проголосовали все.

## 6. Характерная ошибка: голос за свой рифф

Код **403**. Тело:

```json
{"code": "forbidden", "detail": "Нельзя голосовать за свой рифф"}
```

Голос не создаётся. `your_vote_riff_id` не меняется. Ошибка возможна, когда раунд уже на стадии `voting`, рифф принадлежит этому раунду, а `author_id` риффа совпадает с игроком сессии. Свой рифф в чтении раунда отмечен `is_own: true`. Интерфейс показывает поле `detail`.

Чтобы увидеть именно этот ответ, у участника должен быть сохранённый рифф. Если своего риффа нет, выбрать его нельзя.

Другие отказы сюда не входят. Их можно отличить по `detail`: нет сессии — `Нужно войти` (401); нет заголовка CSRF или чужой `Origin` — `Запрос не прошёл проверку CSRF` (403); нет такого раунда или вызывающий не в комнате — `Раунд не найден` (404); стадия не `voting` — `Сейчас нельзя голосовать` (409); риффа нет в раунде — `Рифф не найден` (404); голос уже сохранён — `Вы уже проголосовали` (409). Неразборчивый UUID даёт 422 от проверки тела, это не отказ правила голосования.

## 7. Пример успешного вызова

Участник «Гость» состоит в раунде `22222222-2222-4222-8222-222222222222`. Стадия раунда — `voting`. Чужой рифф — `11111111-1111-4111-8111-111111111111`, у него `is_own` равен `false`. Своего голоса ещё нет. Эти UUID обозначают такие объекты в живом раунде; сервер не хранит их как постоянные константы. Значение куки берётся из `Set-Cookie` и в запрос подставляется целиком.

```http
POST /api/v1/rounds/22222222-2222-4222-8222-222222222222/votes HTTP/1.1
Host: localhost:8000
Content-Type: application/json
X-CSRF-Protection: 1
Cookie: riff_session=<значение из Set-Cookie>

{"riff_id": "11111111-1111-4111-8111-111111111111"}
```

Ожидаемый ответ:

```http
HTTP/1.1 201 Created
Content-Type: application/json

{"riff_id": "11111111-1111-4111-8111-111111111111"}
```

Следующий `GET /api/v1/rounds/22222222-2222-4222-8222-222222222222` с той же кукой содержит `"your_vote_riff_id": "11111111-1111-4111-8111-111111111111"`.

## 8. Пример ошибки

Тот же участник и тот же раунд на стадии `voting`. Вместо чужого риффа передан свой: `33333333-3333-4333-8333-333333333333`, в чтении раунда у него `is_own` равен `true`.

```http
POST /api/v1/rounds/22222222-2222-4222-8222-222222222222/votes HTTP/1.1
Host: localhost:8000
Content-Type: application/json
X-CSRF-Protection: 1
Cookie: riff_session=<значение из Set-Cookie>

{"riff_id": "33333333-3333-4333-8333-333333333333"}
```

Ожидаемый ответ:

```http
HTTP/1.1 403 Forbidden
Content-Type: application/json

{"code": "forbidden", "detail": "Нельзя голосовать за свой рифф"}
```

Запись голоса не появляется. Повторное чтение раунда не меняет `your_vote_riff_id` из-за этого запроса.
