# Архитектурные решения

Каталог подготовлен для ADR следующих лабораторных работ. В лабораторной № 1
согласованные ADR ещё не оформлены; текущее устройство каркаса описано
в [разделе архитектуры корневого README](../../README.md#architecture).

Будущая запись `NNNN-краткое-название.md` должна включать статус, контекст,
рассмотренные варианты, принятое решение и последствия. Например, отдельного
обоснования потребуют протокол игровых событий, серверный таймер и стратегия
хранения черновиков. Эти примеры не означают, что решения уже приняты.
